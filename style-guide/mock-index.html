画面モック

全 43 画面。

製品の DOM から npm run mock:sync が書き出した生成物です。手で編集しないでください。 画面名を押すと枠（iframe）で開きます。幅は下の切り替え、または行ごとの「スマホ」「PC」から選べます。

枠で見る ホーム（スマホ）

既定はスマホ 390px。PC は 1280px の枠で開きます。枠の中は製品と同じ CSS で描くので、 メディアクエリもその幅で効きます。撮った PNG（390 / 1280）は storage/mock-shots/ にあり、コミットしません。
