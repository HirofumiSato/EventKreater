  • 高橋 直樹

    共同幹事 ／ 名簿と売上を見られる

  1. 1催しの名前と開催日時 *何をいつ開くか。チラシにも告知ページにも出ます。必須

    開催日時

    11:00〜15:00

    開始と終了は両方必須です。1件以上、8件まで。参加者は出席するときに1つ選びます。

  2. 2費用プラン *参加者が選ぶ金額です。あとから追加できます。必須

    費用プラン *

    出席者がいるため、共通料金と男女別料金の切り替えはできません。金額・プラン名・補足は変更できます。

    1,500円（1ドリンク付）

    1,000円

    無料（小学生まで）

    金額は整数の円です。0円は「無料」と表示します。参加者は全員この金額から選びます。

  3. 3開催場所 *会場名だけでも保存できます。雨天時の方針もここで決めます。必須

    開催場所 *

    7桁の数字（ハイフン可）を入れて検索すると、都道府県・市区町村・町域が入ります。見つからないときは手入力してください。

    公開ページの表示: 河川敷公園 第2広場

    郵便番号から入れると都道府県・市区町村・町域が自動で入ります。オンライン開催など場所が決まっていないときは、会場名だけでも保存できます。

  4. 4定員と申し込み期限どちらも任意です。空欄なら制限なしで受け付けます。任意

    空欄なら期限はありません。この日時（日本時間）になると、新しい申し込みと回答の変更を止めます。取消はできます。告知URLは開いたままです。

  5. 5チラシ作らなくても保存できます。あとから作り直せます。任意

    チラシ生成

    タイプ・背景・文字の配置・配色の 4 ステップで選んでから保存します。候補を作り直しても回数は減りません。チラシを作成・変更して保存したときだけ 1 回消費します。手元の画像をアップロードする場合は回数を消費しません。

    このイベントでチラシを作成・変更できるのは、残り 3 回（最大 3 回）

    ダウンロード

    Canva などで作った画像（JPEG / PNG / WebP、8MBまで）を、そのままチラシにできます。縦長の画像をおすすめします。

  6. 6公開状態受付を止めるときは主催一覧の「削除・停止」から行います。任意

    公開中

    公開状態はここでは変えられません。受付を止めるときは主催一覧の「削除・停止」から行います。
