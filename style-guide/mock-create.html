新規イベント作成

月額プランで公開中のイベント 7 / 8 件（あと1件公開できます）。

必須の入力はあと 3 つです。

  1. 開催日時

    開始と終了は両方必須です。1件以上、8件まで。参加者は出席するときに1つ選びます。

  2. 費用プラン *

    チェックを入れると、各プランを男性用・女性用に分けて金額を設定できます。プラン名は組で共通になります。1プランが2件として数えられ、合計8件までです。

    金額を入れてください

    金額は整数の円です。0円は「無料」と表示します。参加者は全員この金額から選びます。

  3. 開催場所 *

    7桁の数字（ハイフン可）を入れると、都道府県・市区町村・町域が入ります。見つからないときは手入力してください。

    郵便番号から入れると都道府県・市区町村・町域が自動で入ります。オンライン開催など場所が決まっていないときは、会場名だけでも保存できます。

  4. 公開ページに「対象」として出ます。チラシでは、人が出る催しの年代と熱量にだけ使います。空欄でも、題が人を含めば人物は出ます。

    空欄なら期限はありません。この日時（日本時間）になると、新しい申し込みと回答の変更を止めます。取消はできます。告知URLは開いたままです。

  5. イベントページのテーマ

    標準はじめてならここから

    背景と紙面の性格の 2 ステップで選んでから保存します。文字の配置・配色・題名色は、 写真に合わせて自動で決まります。候補を作り直しても回数は減りません。チラシを 作成・変更して保存したときだけ 1 回消費します。手元の画像をアップロードする場合は 回数を消費しません。

    この下書きでチラシを作成・変更できるのは、残り 3 回（最大 3 回）
