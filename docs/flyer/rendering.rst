文字合成
========

基準キャンバスは 1080×1528 px（A4 縦 210:297）です。背景が別サイズでも、中央を基準に覆うように拡大してからこのサイズへ切り出します。出力は品質 90 の JPEG です。

ゾーン
------

横方向の本文幅は 920 px（左右 80 px）です。

.. list-table::
   :header-rows: 1
   :widths: 12 22 66

   * - ゾーン
     - Y 範囲
     - 内容
   * - A
     - 160–220
     - テンプレートのカテゴリラベル
   * - B
     - 240–660
     - タイトル。最大 3 行、高さ 420 px
   * - C
     - 720–980
     - 日付、時間、雨天時の対応
   * - D
     - 1040–1520
     - 場所、費用、定員
   * - E
     - 1620–1760
     - アクセントの罫線

タイトルのフォントサイズ
------------------------

:func:`src.adapters.renderer.layout_calculator.calculate_optimal_font_and_lines` が、幅 920 px・高さ 420 px に収まるサイズを二分探索します。探索範囲は 44 px から 92 px で、行間は字高の 1.3 倍です。

タイトルが 10 文字未満のときは字間を 15 px 足し、ブロックをゾーン B の上寄りに置きます。短い見出しがゾーン中央で浮くのを抑えるためです。

可読性
------

文字色と、その矩形の平均色から WCAG 2.1 の相対輝度とコントラスト比を計算します。通常文字の合格ラインは 4.5 です。下回るときは、文字色との対比が取れる黒または白の局所バックドロップを、足りる不透明度まで足します。

タイトル領域のエッジ強度（``FIND_EDGES`` の分散）が 500 以上のときは、背景側へ半径 12 px のぼかしをかけ、文字に 2 px の縁取りを付けます。平坦な単色背景ではこの処理は走りません。

フォント
--------

テンプレートごとに明朝、ゴシック、太ゴシックを使い分けます。同梱フォントが無い環境では、Windows の Noto / 游ゴシック / メイリオ、macOS のヒラギノや AppleGothic、Linux の Noto Sans CJK を順に探します。どれも読めないときは :class:`src.domain.exceptions.FontRenderError` です。
