Uvicorn
=======

目的
----

FastAPI アプリを ASGI サーバーとして起動します。画像生成の待ち時間中も、イベントループは他のリクエストを受けられます。

使い方
------

プロジェクトルートで実行します。作業ディレクトリが違うと ``src`` を解決できません。

.. code-block:: powershell

   python -m uvicorn src.main:app --reload

``src.main:app`` はモジュール ``src.main`` の変数 ``app`` です。``--reload`` はソース変更でプロセスを再起動します。

確認先は次のとおりです。

* http://127.0.0.1:8000/health
* http://127.0.0.1:8000/docs

Tips
----

* ポート 8000 が使用中なら ``--port 8765`` のように変えます。
* ``--reload`` は開発用です。常時起動では外し、TTL 掃除タスクが二重にならないようにプロセスは 1 つにします。
* アプリは import 時に ``create_app()`` します。環境変数はプロセス起動前に揃えてください。起動後に変えても、動いているプロセスの設定は変わりません。
* ``uvicorn`` 実行ファイルが PATH に無いときは、``python -m uvicorn`` を使います。
