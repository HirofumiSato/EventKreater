Pillow
======

目的
----

背景画像の上に、テンプレートごとの文字と遮光を決定論的に描きます。ネットワーク通信はしません。

使い方
------

実装は ``src/adapters/renderer/`` です。

* ``layout_calculator.py`` がフォントサイズの二分探索、相対輝度、コントラスト比、高周波の判定を持ちます。
* ``PillowFlyerRenderer.render_flyer`` が 1080×1528（A4 縦）の JPEG バイト列を返します。

タイトル枠は幅 920 px、高さ 420 px、最大 3 行です。探索するフォントサイズは 44 px から 92 px です。

Tips
----

* レンダラーから ``openai`` や ``httpx`` を import しないでください。テストがソースを検査しています。
* ``ImageDraw.textbbox`` の座標は float です。幅と高さは ``int`` に変換してから比較・描画します。
* 日本語フォントが同梱されていない環境では、Windows の Noto / 游ゴシック / メイリオ、macOS のヒラギノ、Linux の Noto CJK を順に探します。
* コントラスト比 4.5 未満のときは局所的な黒または白のバックドロップを足します。単色背景のテストでも、明るい背景に白文字ならこの処理が走ります。
* 出力 JPEG の品質は 90 です。透過は最終段で RGB に合成してから保存します。
