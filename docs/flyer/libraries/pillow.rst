Pillow
======

目的
----

背景画像の上に、テンプレートごとの文字と遮光を決定論的に描きます。ネットワーク通信はしません。

使い方
------

実装は ``src/adapters/renderer/`` です。

* ``design.py`` が目盛り・余白・色の役割・3 種の変奏を持ちます。Pillow を使わないので、数値だけを検証できます。
* ``poster.py`` の ``build_poster_plan`` がスロットの文字・大きさ・位置・色を決め、``draw_poster`` が描きます。組み立てと描画が分かれているため、目盛りと縦のリズムを画像なしでテストできます。
* ``layout_calculator.py`` が目盛りからの字の選択（``fit_to_scale``）、相対輝度、コントラスト比、高周波の判定を持ちます。
* ``layouts.py`` が積みの基準位置（``split`` / ``top`` / ``center`` / ``bottom``）を持ちます。
* ``PillowFlyerRenderer.render_flyer`` が 1080×1528（A4 縦）の JPEG バイト列を返します。

文字サイズは比 1.25 の目盛り（17〜163 px）からだけ選び、「枠に入る最大値」は探しません。タイトル枠は幅 888 px、高さ 480 px、最大 3 行で、163 / 130 / 104 / 83 / 66 / 53 / 42 の大きい順に試して最初に収まった段を採ります。1 行に収まらないときは意味の区切りで行を分け、最終行が短ければ右端へぶら下げます。縦位置はすべて 8 px の倍数です。

Tips
----

* レンダラーから ``openai`` や ``httpx`` を import しないでください。テストがソースを検査しています。
* ``ImageDraw.textbbox`` の座標は float です。幅と高さは ``int`` に変換してから比較・描画します。
* 日本語フォントが同梱されていない環境では、Windows の Noto / 游ゴシック / メイリオ、macOS のヒラギノ、Linux の Noto CJK を順に探します。
* コントラスト比 4.5 未満のときは、紙の色を薄く重ねます（``veil_alpha``）。黒や白の帯・角丸の板は使いません。単色背景のテストでも、明るい背景に白文字ならこの処理が走ります。
* 差し色は文字に使う前に ``safe_accent`` を通します。黄や藍はそのままでは明るい紙に載りません。
* 出力 JPEG の品質は 90 です。透過は最終段で RGB に合成してから保存します。
