概要
====

このシステムが引き受ける仕事は、告知に必要な事実を受け取り、スマートフォンのストーリー向けポスターを 1 枚返すことです。利用者はフォントや余白を自分で調整しません。

二つの層
--------

確率的な層と決定論的な層を分けています。

* **確率的な層** は、催しの空気感を英語の背景プロンプトへ翻訳し、文字のない背景画像を得ます。モデルは ``gpt-4o-mini`` と ``gpt-image-1`` です。
* **決定論的な層** は、利用者が入力した文字列を 1080×1528 px（A4 縦）の決まったゾーンへ描きます。同じ入力と同じ背景なら、文字の位置と改行は揺れません。

文字を画像モデルに描かせない理由は、日本語の崩れと、料金や日付の改変を設計上起こさないためです。プレビューもダウンロードも、サーバーが焼き込んだ JPEG だけを使います。ブラウザ側でレイアウトを計算し直す経路はありません。

入力するもの
------------

必須なのは催し名、開催日、開催時間、費用、場所、テンプレートです。雨天時の対応は省略すると「雨天決行」になります。定員は任意です。

テンプレートは次の 3 つです。

.. list-table::
   :header-rows: 1
   :widths: 32 68

   * - ID
     - 想定する場
   * - ``style_1_bar_stylish``
     - バー、ナイトイベント、ライブ、占い。中央揃え、暗い遮光、明朝系。
   * - ``style_2_warm_earth``
     - サロン、ワークショップ、タコパ、撮影会。左揃え、白い角丸カード、ゴシック系。
   * - ``style_3_vibrant_pop``
     - マルシェ、フェス、飯フェス。左上タイトル、半透明の黒パネルとアクセントの枠。

やらないこと
------------

初期版では、ドラッグで文字を動かす編集、自由なフォント選択、印刷入稿用の CMYK PDF、利用者が画像プロンプトを直接書く画面は対象外です。
