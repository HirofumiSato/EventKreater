画像の基本
==========

:doc:`/flyer/overview` と :doc:`/flyer/rendering` は、ポスターを 1 枚のビットマップとして扱います。ビットマップは、色のついた点の格子です。

ピクセルと座標
--------------

点のことをピクセル（px）と呼びます。このシステムの基準は、幅 1080、高さ 1528 です。座標の原点は左上で、右へ X、下へ Y が増えます。ガイドの「Y 範囲 128–176」は、上から 128 px 目から 176 px 目までの帯です。

縦横比は A4 縦（210:297）です。紙の A4 をそのまま縦に置いた形で、幅 1080 に対して高さが約 1527 になります。1080:1528 は 210:297 とほぼ同じ比率です。

背景画像が別の大きさでも、中央を基準に拡大してから 1080×1528 に切り出します。上下や左右が少し欠けることがあります。これを覆うように合わせる、と言います。画像モデルには A4 相当のサイズが無いため、背景は 9:16 の縦長で生成し、ここで A4 に切り出します。

ファイル形式
------------

* **PNG** は、ダウンロードした背景や静的な代替背景に使います。劣化の少ない形式です。
* **JPEG** は、完成品の形式です。写真向けで、ファイルサイズを小さくする代わりにわずかに劣化します。ガイドの「品質 90」は、その劣化の少なさです。100 に近いほど劣化が小さいです。

文字の見た目
------------

* **明朝** は、横線が細く縦線に抑えがある書体です。バー向けテンプレートで使います。
* **ゴシック** は、線の太さが比較的均一な書体です。サロン向けで使います。
* **字間** は文字と文字のあいだの空き、**行間** は行と行のあいだの空きです。
* **中央揃え** は行を枠の中央に置くこと、**左揃え** は枠の左に揃えることです。
* **16 進カラー** の ``#RRGGBB`` は、赤・緑・青をそれぞれ 00 から FF で書く色です。``#FFFFFF`` は白、``#000000`` は黒です。
* **不透明度（アルファ）** は、重ねた色をどのくらい透かすかです。0 は完全に透明、1 は完全に不透明です。ガイドの 0.55 は、およそ半分強を重ねる、という意味です。

可読性
------

背景が明るいのに白い文字を置くと読めません。**コントラスト** は、文字色と背景色の明るさの差です。ガイドが参照する WCAG は、その差の国際的な目安で、通常の文字は比 4.5 以上を合格としています。

差が足りないときは、紙と同じ色を文字の群の下へ薄く重ねます。黒や白の板、角丸のカードは使いません。背景が細かい模様で文字の縁が溶けるときも、縁取りではなくこの薄い幕を濃くします。
