文字合成の前に
================

:doc:`/flyer/rendering` は、完成画像を 1 枚の方眼として説明します。ピクセルと JPEG の意味は :doc:`images` にあります。ここでは、ガイドのスロット表とコントラストの節を読むための補足だけを置きます。

スロットは予約席
----------------

キャンバスは幅 1080、高さ 1528 です。原点は左上で、Y は下へ増えます。スロットは、あらかじめ場所を予約した席です。日付は eyebrow、催し名は title、時刻は meta、場所や料金は facts、雨天の扱いは note、というように種類ごとに席が決まっています。左右の余白は 96 px、本文幅は 888 px です。

テンプレートが変えるのは、書体・揃え方・面の濃さの 3 つだけです。スロットの並びと間隔は 3 テンプレートで共通です。だから「バー向けだからタイトルが下に移動する」とは書かれていません。

タイトル枠
----------

文字に使ってよい幅は 888 px、高さは 480 px です。行は最大 3 行で、フォントサイズは比 1.25 の目盛り（163 / 130 / 104 / 83 / 66 / 53 / 42 px）を大きい順に試し、最初に収まった段を採ります。長いタイトルは小さい段に、短いタイトルは大きい段になります。段の外の値は作りません。

10 文字以下のタイトルは字間を 6 px 広げます。段を飛ばして大きくはしません。余白は写真の主役が使う領域であり、空隙ではなく余白として扱います。

下地と文字色
------------

文字色はテンプレートと、言語モデルが返した強調色で決まります。その色が、実際に文字の背後にあるピクセルと比べて暗すぎ・明るすぎなら、その群の矩形に紙の色を薄く重ねます。合格の目安はコントラスト比 4.5 です。黒や白の板、角丸のカードは使いません。

背景が葉や照明のように細かいときは、平均の明るさだけでは読めません。エッジの強さを測れるようにしてありますが、縁取りは付けません。紙面の文法が「区切りは罫線」だからです。

書体ファイル
------------

明朝・ゴシックは、プログラムが形を計算するのではなく、PC 上のフォントファイルを読みます。同梱が無いときは Windows、macOS、Linux の順で既知のファイルを探し、最初に開けたものを使います。どれも無いときだけ、文字合成は失敗します。

出力は、このキャンバスを品質 90 の JPEG にしたものです。ブラウザは受け取った画像をそのまま表示し、位置を計算し直しません。
