## 1. 結論

ホームの不満は、**1つの構造的な原因**から来ている。

> ホームが「マーケティングLP」「使い方の説明」「参加者向けの案内所」「ナビゲーション」の4役を同時に背負い、どれが主役か決めていない。

その結果、次が同時に起きている。

| 症状 | 実測された裏付け |
| :--- | :--- |
| 画面の役割がわからない | ファーストビューに操作可能な要素が 7 つ。主CTAが 3 つ並び、`320px` では縦に 3 段になる |
| 何を伝えたいかわからない | 本文は全体で 642 文字。うち並列な主張が 8 ブロック（機能4・手順3・注意1）。見出しの階層に主従がない |
| デザインの誘引力がない | 画像が **0 枚**。成果物であるチラシを見せていない。デスクトップのヒーローは 992×282 のうち右側 約300px が空白 |

つまり、**個別の見た目を直す前に、役割を1つに絞る必要がある**。

| 幅 | 並び | ブロック高 |

### 3.4. 機能カードの孤立

`.card-grid` は `768px` 以上で3列固定（`src/styles/components.css`）。カードは4枚あるため、**3枚 + 孤立した1枚**になる。

| 幅 | 列 | カード位置 |

| 1440px | `320px 320px 320px` | 1段目 3枚（y394–557）、2段目 1枚（y573–714） |
| 390px | 1列 | 4枚縦積み |

デスクトップのスクリーンショットで、2段目左端に1枚だけ残る。これは「作りかけ」の印象を直接作る。

### 3.5. 書式

| 役割 | サイズ | 対象 |
| :--- | ---: | :--- |
| h1 | 36px / 28px（800px以下） | ヒーロー |
| セクション見出し | 24px | 「使い方」「イベントを探している方へ」 |

| カード本文 | 14px | — |
| ボタン | 14px | — |
| eyebrow | 12px | — |

**機能カードの見出しが h2 かつ 16px**。「使い方」（h2・24px）と同じ階層なのに見た目は本文並み。見出し構造と視覚階層が一致していない。

### 3.6. 余白

セクション間はすべて 20px（`--stack` の `gap: 1.25rem`、`src/styles/components.css`）。ヒーロー、機能、手順、注意の**すべてが同じ間隔**で並ぶため、塊の切れ目が読めない。

### 3.7. コントラスト（参考）

本文 `#3f3c36` on `#ffffff` = 10.99:1、補足 `#6b655c` on `#f4f3ef` = 5.19:1、eyebrow `#b4332a` on `#ffffff` = 6.09:1。

**可読性は問題ない。** 今回の不満は配色ではなく、構成と優先順位の問題である。

## 5. スタイルガイドとの差分

`style-guide/index.html` の「出欠簿」は、**入力画面としては一貫している**。罫線、影なし、0.25rem角、状態色の固定。問題は、その規約を**LPにそのまま適用したこと**にある。

| 規約 | 入力画面での意味 | LPでの帰結 |
| :--- | :--- | :--- |
| 面は罫線で分ける | 入力項目の区切り | 白い箱の反復。社内ツールの説明書に見える |
| 影を付けない | 静けさ | 階層の手がかりがゼロ。全カードが同格に見える |
| 主操作は一つ | 送信ボタン | **守られていない**（A-02） |
| 色は状態だけ | 出欠の緑・黄・赤 | ブランドの印象が残らない（C-03） |
| 書体は一種類 | 統一 | 見出しと本文の差が小さく、視線のリズムが出ない |

**結論:** 規約を壊すのではなく、LP用の表現（スタンプ型ラベル、番号付きステップ、墨の CTA 帯、罫線で分割したパネル）を追加し、`style-guide/index.html` に追記する。追記しないと同じ逸脱が次の画面で再発する。

## 6. 改修の方針

### 6.1. ホームの役割を1文で定義する

> **初見の幹事が「自分のためのサービスだ」と理解し、無料で1つ作り始める画面。**

- 主対象: 新規の幹事
- 参加者は主役にしない（参加者は主催者が共有した `/events/[id]` から来る）
- 主KPI: ヒーローの主CTAクリック
- 残す制約: C1〜C8
- 変えること: 参加者向け案内を FAQ へ降格し、最後を CTA にする

### 6.2. フェーズ分割

| フェーズ | 内容 | 解消する指摘 | 触るファイル |
| :--- | :--- | :--- | :--- |
| P0 | コピー、セクション見出し、CTA一本化、最後をCTAに | A-01, A-02, A-03, B-01, B-02, B-06, B-07 | `page.tsx`, `site.ts`, `Navbar.tsx` |

| P2 | 機能3行パネル、番号付きステップ、FAQ | B-03, B-04, B-05 | `page.tsx`, CSS |
| P3 | 余白、モバイルヘッダー、モーション | C-01, C-02 | CSS, `Navbar.tsx` |
| P4 | スタイルガイドへ追記 | — | `style-guide/index.html` |

P0 だけで「何の画面か」はほぼ解消する。P1 までで対外に出せる状態になる。

## 9. 見た目の再設計（V1〜V5）

P0 は情報の並べ替えに留まり、画面の印象は変わらなかった。ここでは紙と帳票としての見た目を作り直した。

### 9.1. 方針

`c_plus_a`（ポスター主体の2カラム・ヒーロー）と、角 0 の全面適用を採用した。

- ホームだけ墨地の帯を敷き、告知の成果物であるチラシを最初に見せる。
- 機能と手順はカードの箱をやめ、横罫線と等幅の番号で区切る。
- 最後の一押しだけ朱で面を塗る。墨・紙・朱の3色に絞る。
- 角はすべて 0。丸みで柔らかくせず、罫線の強さで読ませる。

### 9.2. 変更したもの
